# Personal Portfolio Website

A responsive personal portfolio made with plain HTML, CSS, and JavaScript. No build tools or external libraries are required.

## Files
- `index.html` — semantic page structure and content
- `style.css` — layout, colors, responsive breakpoints, and reduced-motion support
- `script.js` — theme switcher, project filters, copy-email action, and form validation

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Before submitting
1. Replace **Alex Morgan** and the example biography with your own information.
2. Replace `alex.morgan@example.com` with an email address you are comfortable publishing.
3. Replace the sample projects with real projects. Add working repository/demo links if available.
4. Test mobile and desktop layouts.
5. Run `index.html` through the W3C Nu HTML Checker: https://validator.w3.org/nu/
6. Check the exact four-extra requirements against your course's Portfolio Rubric. This demo implements:
   - Light/dark theme toggle
   - Project category filtering
   - Copy email to clipboard
   - Client-side contact form validation
7. Publish the repository using GitHub Pages: Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Important
The contact form is a front-end demo only. It validates input but does not send or store messages. Do not claim that it sends messages unless you connect it to a real backend or form service.
